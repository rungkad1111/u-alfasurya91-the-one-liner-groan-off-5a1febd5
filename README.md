# The One-Liner Groan-Off

[![The One-Liner Groan-Off](https://make.fun/badge/u-alfasurya91-the-one-liner-groan-off-5a1febd5.svg)](https://make.fun/c/u-alfasurya91-the-one-liner-groan-off-5a1febd5)

One original one-line dad joke (at most 140 characters), written for the
[The One-Liner Groan-Off](https://make.fun/c/u-alfasurya91-the-one-liner-groan-off-5a1febd5)
competition on make.fun, where a judge model picks the funniest groan head to head.

## Entry

> I taught my kids parallel parking is just Tetris, but with insurance.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

Requires Node 22.18+ (the grader runs Node 22.23.4). No dependencies.
